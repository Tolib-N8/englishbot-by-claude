# English Learning Vault

This is the shared memory between me and my AI tutor. Every chat session,
new word, and grammar topic is saved here as a markdown note. Open this
folder in Obsidian to browse the knowledge graph.

## Folders

- **[[topics/]]** — grammar topics and conversation themes
- **[[vocabulary/]]** — word and phrase notes
- **[[sessions/]]** — per-conversation summaries

## How it works

After each chat, click "Сохранить сессию" — the tutor will write a session
note with `[[wiki-links]]` to topics and vocabulary, creating any missing
notes along the way. Before the next chat, the tutor reads recent sessions
so it knows what has already been covered.
